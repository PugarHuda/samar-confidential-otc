# Samar suite hub

Static landing that links the three confidential-finance apps in this repo and tells the composability story. No contracts, no SDK — a single self-contained page.

**🔗 Live:** https://samar-hub.vercel.app

Links out to:
- [Samar OTC desk](https://samar-otc.vercel.app) — `packages/web`
- [Confidential Wrapper Registry](https://samar-wrapper.vercel.app) — `packages/wrapper`
- [Confidential Airdrop](https://samar-airdrop.vercel.app) — `packages/airdrop`

See the [root README](../../README.md) and [SUBMISSION.md](../../SUBMISSION.md) for the full picture.
